## Candidate semantics note (WINABC vs Sogou)

Recent A/B log review shows the two IMEs do differ in gate/lifecycle behavior, but both may emit non-lexical candidate slots:

- WINABC sample (`PIPE ni`) includes main Chinese candidates plus symbol/replacement slots (for example `...|逆|�|溺|�|...`).
- Sogou sample (with Force36c) includes Chinese candidates plus one punctuation-like slot (`(*?`)??`), likely an emoji/symbol candidate path rather than a hard decode failure.

Practical rule for host decoding:

- do not classify a single symbol-like candidate as corruption by default
- only treat decode as lossy when the entire token/page is clearly unreadable (e.g. all question marks)
